# Royal Blinds brand assets

These original PNG assets were retrieved from the company's website to implement the logo supplied by the user. They are bundled locally so the application does not require external image requests.

- `royal-blinds-logo.png`: https://www.royalblinds.com/wp-content/uploads/2024/01/RB-Logo1.png — original full logo, 749 × 290.
- `royal-blinds-icon.png`: https://www.royalblinds.com/wp-content/uploads/2024/01/RB-Favicon-300x300.png — original official icon, 300 × 300.

The original image bytes, proportions, colours and transparency are preserved. The full logo appears on a light background; the official icon is used in the compact sidebar, identity badges and browser favicon. These assets identify the company whose portfolio informs this independently developed application.
